## 0. 설계 규칙 (직관성)

### 0-1. 서열 원칙
1. **등급이 먼저입니다.** 같은 조건이면 SSR > SR > R > N > C입니다. 등급 차이는 ①스킬 계수 예산과 ②등급별 기본 능력치, 두 겹으로 보장합니다.
2. **같은 등급·같은 클래스 안에서는 시트의 '순위'를 그대로 지킵니다.** 순위가 높을수록 단일 대상 피해와 다수 대상 피해를 합친 가치가 큽니다.
3. **하위(약식판) 캐릭터는 원본보다 항상 약합니다.** 예: 문추 < 관우, 장보 < 장각, 단아 < 화타.
4. **특화 캐릭터는 자기 분야에서만 같은 등급 주력보다 좋습니다.** 범용 가치는 낮게 둡니다.

### 8-3. 화면 표시 — 하지 않음 (사용자 결정)

## 9. 진영 보너스 규칙 — 성격은 살리고 몰빵은 막기 (사용자 승인)

### 9-1. 4진영 성격과 보너스
| 진영 (리더 ★5) | 성격 | 1명 / 2명 / 3명 이상 | 같은 진영 3명 이상 시 |
|---|---|---|---|
| 군웅 (호야) | 난세의 무력 — 공격 | 공격력 +4 / +8 / **+12%** | 전투 시작 기력 +10 |
| 위 (조조) | 정예 속공 — 치명타 | 치명타 확률 +4 / +8 / **+12%** | 전투 시작 기력 +10 |
| 촉 (유비) | 인의·수호 — 버티기 | 받는 피해 -4 / -8 / **-12%** | 전투 시작 기력 +10 |
| 오 (손권) | 강동의 결의 — 저항 | 최대 체력 +4 / +8 / **+12%**, 상태이상 저항 +7 / +14 / **+20%** | 전투 시작 기력 +10 |

- 보너스는 **리더와 같은 진영 아군에게만** 적용됩니다. 리더 본인도 포함되고, 리더가 ★5이고 살아 있어야 합니다.
- **최대치는 3명입니다.** 4~5명이어도 늘지 않습니다.
- **리더 2명을 함께 편성하면 두 진영 보너스가 모두 켜집니다.** 예: 조조 + 위 1명, 유비 + 촉 1명.
  - 그래서 '3명 + 2명' 혼합 편성이 5명 몰빵보다 유리하거나 같습니다.
  - 5명 몰빵은 진영 던전에서만 의미가 있습니다.
- 공격 진영(군웅·위)과 방어 진영(촉·오)의 체감 가치는 모두 **최대치에서 약 +10%**로 맞춥니다. 구현 후 측정합니다.

### 9-2. 엔진 수정 E1 — 스킬도 치명타 적용 [확인된 문제]
- **문제:** 지금 치명타는 일반 공격에만 터집니다. 기본값은 확률 12%, 피해 1.5배입니다(`contentBattle.ts:970`). 스킬 피해 `hurt()`는 치명타 값을 항상 false로 넘깁니다(`:171`과 호출부).
- **수정:** 스킬 피해도 같은 치명타 확률과 치명타 피해를 적용합니다. 지속 피해(화상·독·장판 틱)는 제외합니다.
- **효과:** 조조, 위 진영 보너스, 손권, 여포 5성, 순욱 5성, 원술 5성이 설명대로 동작합니다.
- **E2 (측정 후 판단):** 위가 측정에서 군웅보다 크게 낮으면 위 치명타 확률을 +5 / +10 / +15%로 올립니다.
