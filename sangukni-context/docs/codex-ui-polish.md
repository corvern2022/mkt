# 화면 정리 잔여 항목 — Codex 전달 (기준 2e04f7f, 10/6 야간 실화면 검수 결과)

이 문서는 `codex-next-batch.md`, `codex-wording-final.md`, `codex-ios-perf.md`에 **들어 있지 않은** 화면 문제만 모은 것이다. 문구 수정은 문구 최종본을 따른다.

## A. 설정 화면
1. '튜토리얼 다시보기'와 '데이터 초기화'가 가이드 진행 중에도 바로 보인다(`ui/dom/settings.ts`).
   - 강제 튜토리얼(1-1~1-6) 동안에는 숨긴다.
   - 그 이후에는 설정 맨 아래 '기타' 접힘 안으로 옮긴다.
   - '다시보기'를 누르면 확인창을 띄운다. 지금은 확인 없이 바로 타이틀로 돌아간다.
2. '삼국냥전 키우기 · v0.5', '계정 (로컬)', '계정·저장 상태 확인' 표시
   - 게임 이름을 '삼국냥전 v0.5'로 통일한다.
   - 계정 관련 표시는 서버 연동 전까지 숨긴다.

## B. 지역 이동 배너
- 새 지역에 도착하면 "1-6 야영지 남문" 배너가 화면 가운데에 큰 빈 카드처럼 뜬다. 같은 시점에 대사창이 뜨면 둘이 겹친다.
- 수정:
  - 배너는 화면 상단, 지역 라벨 바로 아래에 얇은 띠(높이 40px 이하)로 1.2초간 보여 준다.
  - 대사창이 떠 있으면 배너를 띄우지 않는다. 상단 지역 라벨만 바꾼다.

## C. 대사창 여백 (2e04f7f에서 일부만 반영)
- 1줄 대사인데도 본문 아래와 [다음] 버튼 아래에 빈 공간이 크다.
- 수정:
  - 대사창 높이는 내용에 맞춘다. 최소 높이를 없앤다.
  - 여백은 위·아래 14px, 좌·우 16px로 한다.
  - [다음] 버튼은 본문 바로 아래 오른쪽에 둔다(간격 6px).
- 검수: 1줄·2줄·3줄 대사 캡처에서 위·아래 여백이 같아야 한다.

## D. 팝업 연속 노출
- 집사 레벨업 팝업을 닫자마자 이름 정하기 대사 3줄과 팝업이 이어서 뜬다.
- 수정:
  - 팝업이 연달아 열릴 때는 1초 이상 간격을 둔다.
  - 레벨업 팝업은 자동으로 닫히는 토스트("집사 Lv.2")로 바꾼다. 확인 버튼을 누를 필요가 없게 한다.

## E. 소환 결과·확률 화면
1. 결과 카드에 "NEW" 배지와 "신규 획득" 글자가 함께 나온다.
   - 신규는 NEW 배지만 남긴다.
   - 중복은 "카드 +1"로 표시한다.
2. 결과를 등급순으로 정렬한다. SSR → SR → R → N → C 순서로, 좋은 결과가 앞에 오게 한다.
3. SR 이상이 나오면 해당 카드가 뒤집힐 때 짧은 강조 효과를 준다. 기존 연출 자원을 쓴다.
4. 확률 창:
   - "0.60000%"를 "0.6%"로 바꾼다. 의미 없는 끝자리 0은 지운다.
   - 목록을 등급별로 묶어서 SSR부터 보여준다.

## F. 7일 성장 여정 화면
1. "미션 60개 달성 시 영입"과 "미션 보상 0 / 60"이 같은 내용이다. 진행 막대 한 줄 "초선냥 영입까지 0/60"만 남긴다.
2. 하단 "누적 보상 · 0/70"이 위의 60과 헷갈린다.
   - 70은 전체 미션 수다. "전체 미션 0/70"으로 이름을 바꾸거나 삭제한다.
3. 같은 제목 "지역 몬스터 처치"가 0/20, 0/50 두 줄로 나온다.
   - "몬스터 20마리 처치", "몬스터 50마리 처치"로 숫자를 제목에 넣는다.
4. "다른 완료 방법" 버튼은 무슨 뜻인지 알 수 없다.
   - 버튼을 없애고 미션 아래에 한 줄로 쓴다. 예: "또는 몬스터 300마리 처치"

## G. 영웅 상세 화면
1. 화면 왼쪽에 같은 모양의 "<" 버튼이 두 개다. 위쪽은 뒤로가기, 가운데는 이전 영웅이다.
   - 뒤로가기는 "×" 또는 다른 모양으로 바꾼다.
   - 이전·다음 영웅 버튼은 좌우 대칭으로 둔다.
2. "방어력 +0.0%": 장비가 없으면 "방어력 0%"로 표시하거나 그 줄을 숨긴다.
3. 레벨업 버튼 상태
   - 사료가 부족하면 회색으로 표시한다. 이건 현재 정상 동작이다.
   - 버튼 위의 "사료가 부족합니다. 방치 보상이나 레벨 던전에서…" 문장을 "사료 부족"으로 줄인다. 문구 최종본에도 들어 있다.

## H. 스테이지 이동 화면
- '하드' 탭을 눌러도 화면이 바뀌지 않고 잠금 안내도 없다.
  - 잠겨 있다면 탭을 회색으로 하고 "일반 8-30 클리어 시 열림" 같은 안내를 띄운다.
  - 실제 해금 조건은 코드에서 확인한다.
- 긴 설명문, '시나리오 1~8' 탭, '일반 1-N' 표기는 문구 최종본을 따른다.
