# 초반 강제 튜토리얼 · 소환권 1장 처리 · 강조 연출 — 제안 (기준 2e04f7f)

## 1. 초반 강제 튜토리얼 [사용자 결정: 강제 튜토리얼로 해결]

### 문제 (실측)
- 보스 버튼만 누르면 3분 만에 1-6에 도착한다. 이때 가이드는 3단계에 멈춰 있다.
- 그 결과 궁수냥 합류, 4·5번째 칸, 첫 소환이 모두 빠진다.
- 가이드를 따라가도 지역 이동이 먼저 일어나서 이야기 대사가 한 지역씩 늦게 나온다.

### 제안 규칙
- **적용 구간:** 1-1 ~ 1-6 첫 10연까지(가이드 1~18단계). 그 이후는 지금처럼 자유 진행.

| 규칙 | 내용 |
|---|---|
| 지역 이동 | 튜토리얼 구간에서는 **자동 이동을 멈춘다.** 현재 가이드가 그 지역의 마지막 단계일 때만 다음 지역으로 이동한다. 보스 처치 보상을 받은 뒤 이동한다 |
| 보스 버튼 | 현재 가이드가 '보스 처치'일 때만 연다. 성장 단계(레벨업·편성·상자)가 남아 있으면 보스 버튼 대신 그 단계로 안내한다 |
| 화면 막기 | 성장 단계에서는 화면을 어둡게 덮고(스포트라이트) 대상 버튼 하나만 누를 수 있게 한다. 다른 탭과 버튼은 누를 수 없다 |
| 사냥 | 처치 단계에서는 전투가 자동으로 진행된다. 화면을 막지 않고 하단 가이드만 표시한다 |
| 대사 | 가이드 단계가 바뀔 때만 나온다. 지역 이동과 순서가 어긋나지 않는다 |
| 끊김·재접속 | 튜토리얼 진행 상태를 저장한다. 앱을 다시 열면 그 단계의 화면 막기부터 다시 시작한다 |
| 기존 계정 | 이미 1-6을 넘은 계정에는 적용하지 않는다. 빠진 합류(궁수냥)와 첫 소환 우편은 접속 시 한 번에 지급한다 |
| 건너뛰기 | 제공하지 않는다. 대사 [건너뛰기]는 대사만 넘긴다 |

### 단계별 흐름 (1-1 ~ 1-6)
1. 1-1 사냥 → 보스 → 클리어 보상
2. **[막기]** 영웅 화면 → 호야냥 레벨업 → 전투로 복귀
3. 1-2로 이동 → 사냥 → 보스
4. **[막기]** 레벨업 1회
5. 1-3 → 보스
6. **[막기]** 사료 상자 열기 → 레벨업
7. 1-4 → 보스 → 궁수냥 합류 연출
8. **[막기]** 편성에 궁수냥 넣기
9. 1-5 → 보스
10. **[막기]** 금화 상자 열기
11. 1-6 → 보스
12. **[막기]** 우편 → 소환권 받기 → 초보 모집 10연 → 5번째 칸 편성
13. 자유 진행 시작. 자동 보스 튜토리얼은 그다음 단계로 이어진다.

- 위치: 지역 이동은 `fieldLobby.ts` `advanceAfterGuide`/`fieldAutoAdvanceReady`, 보스 버튼은 `fieldBossHud.ts`, 가이드 순서는 `referenceGuide.ts` `BEGINNER_ADVENTURE_GUIDE`.
- 검수:
  - 실제 터치 플레이로 1-1부터 1-6 첫 10연까지 진행한다.
    - 보스만 연타하는 경로와 가이드를 따르는 경로 두 가지 모두 한다.
  - 두 경로 모두 궁수냥 합류, 첫 10연, 5번째 칸이 반드시 일어나야 한다.
  - 대사는 해당 지역에서 나와야 한다.

## 2. 소환권 1장 문제 [사용자 의견: 1회 소환은 필요하지만 '1회'를 강조하면 유저가 싫어함]

### 현재 문제
- 가이드 35단계가 "영웅 1회 소환"을 요구하고 소환권 1장을 준다.
- 그런데 지금은 10회 소환만 가능해서 진행이 막힌다.

### 제안: "1장씩 모아서 10연" 구조. 1회 소환은 기능으로 두되 보여주는 방식을 낮춘다

| 항목 | 내용 |
|---|---|
| 가이드 목표 | "영웅 1회 소환"을 **"소환권 받기"**로 바꾼다. 보상은 소환권 1장 그대로다. 목표 달성 조건은 '받기'이므로 막히지 않는다 |
| 소환권 표시 | 하단 가이드·보상 팝업·소환 화면에서 **"10연까지 7/10"** 형식으로 보여준다. 장수가 아니라 10연까지 남은 진행도를 강조한다 |
| 10장 달성 | 소환 탭에 빨간 점 + "10연 소환 가능". 이때 가이드 목표 **"영웅 10연 소환"** 1회를 넣는다 (기존 10연 가이드와 통합) |
| 1회 소환 버튼 | 소환 화면 하단 큰 버튼은 **[10연 소환]** 하나만 둔다. 1회는 그 옆 작은 텍스트 버튼 **"1장 사용"**으로 둔다. 소환권이 1장 이상 있을 때만 보이고, 보석으로는 1회 소환이 되지 않는다 |
| 문구 | '1회'라는 말을 쓰지 않는다. "1장 사용" / "10연 소환". 결과 화면 제목도 "소환 결과" 하나로 통일한다 |
| 10연 혜택 표시 | 10연 버튼 아래 작은 글씨로 "SR 이상 1명 확정"을 넣는다. **[결정 필요]** 확정 규칙이 없으므로 현재는 표시하지 않는 것이 맞다. 넣으려면 확률 정책을 변경해야 한다 |

- 효과:
  - 막힘이 없어진다.
  - 유저는 '조금씩 모아 10연'을 기대하게 된다.
  - 1회 소환은 필요한 사람만 쓰는 보조 기능이 된다.
- 위치:
  - 가이드 metric `summon` 목표 1인 35행 → 새 metric `ticket-claim`
  - 소환 버튼: `summonPanel.ts:87`
  - 배치: `summonSystem.ts` batches `[1,10]`. 단, 1회는 소환권 전용
- 검수:
  - 소환권 9장 상태에서 가이드가 막히지 않아야 한다.
  - 1장 사용 버튼은 소환권이 0장이면 숨겨져야 한다.
  - 보석으로 1회 소환이 되지 않아야 한다.

## 3. 강조 연출 — 링을 대체할 아이디어 [사용자: 손가락 강조를 원했는데 링이 품질이 낮음]

### 원칙
- 한 화면에 강조는 **한 곳만** 둔다.
- 버튼의 테두리 모양을 바꾸지 않는다(외곽선·링 금지). 버튼 위에 **별도 요소**를 얹는다.
- 글자를 가리지 않는다.
- '동작 줄이기' 설정을 켜면 움직임을 멈추고 정지 이미지만 보인다.

### 추천 조합

| 상황 | 연출 | 설명 |
|---|---|---|
| 강제 튜토리얼 (화면 막기) | **스포트라이트 + 냥발 포인터** | 화면 전체를 60% 어둡게 하고 대상 버튼 모양대로 구멍을 낸다. 모서리 둥글기도 버튼과 맞춘다. 버튼 오른쪽 아래에 고양이 발(냥발) 포인터가 0.9초 주기로 "꾹" 누르는 동작을 반복한다. 누를 때 버튼에 작은 원형 파동이 한 번 퍼진다 |
| 자유 진행 중 가이드 완료 | **반짝임 스윕** | 가이드 독 위로 흰 빛줄기가 1.2초에 한 번 왼쪽에서 오른쪽으로 지나간다. 3회 후 멈췄다가 8초 뒤에 반복한다. 테두리는 바뀌지 않는다 |
| 새 기능·받을 보상 | **빨간 점 배지** | 탭 아이콘 오른쪽 위에 지름 8px 빨간 점. 숫자는 넣지 않는다. 모바일 게임 표준 표시다 |
| 보스 버튼 활성 | **살짝 커졌다 작아지기** | 1.0 → 1.04 → 1.0, 1.5초 주기. 처음 나타날 때 한 번 튀어 오른다 |

### 냥발 포인터 세부
- 크기 48px. 대상 버튼의 오른쪽 아래 1/4 지점을 가리킨다. 화면 밖으로 나가면 왼쪽 아래로 뒤집는다.
- 동작: 들어 올림(0.3초) → 누름(0.15초, 92% 크기) → 대기(0.45초)
- 그림: 기존 화풍에 맞는 **고양이 발바닥 포인터 원화가 필요하다** **[결정 필요]**
  - 원화 담당에게 1장을 요청한다. 흰 발 + 분홍 젤리, 그림자 포함, 512px PNG.
  - 원화가 오기 전 임시로 기존 금화 발바닥 아이콘(`assets/currency/gold-paw-v1.png`)을 써도 되는지 결정이 필요하다.
- 말풍선: 포인터 옆에 짧은 말풍선 하나만 둔다(최대 8자, 예: "레벨업!"). 지금의 "눌러서 보스 도전" 같은 문장은 쓰지 않는다.

### 삭제
- `.learning-target` 외곽선과 애니메이션: `ui/dom/fieldHudLayout.css:112-119`
- `data-learning-label` 말풍선
- 가이드 독 `guide-ready` 링: `fieldHudLayout.css:78, 85`
- 영웅 화면 뒤로가기 버튼 링

### 검수
- 아래 화면을 390×844, 320×740에서 캡처한다.
  - 튜토리얼 단계 5곳(레벨업, 편성, 상자, 우편, 소환)
  - 자유 진행 화면 3곳
- 확인할 것:
  - 강조가 화면에 한 곳뿐인지
  - 글자가 가려지지 않는지
  - 링이나 외곽선이 0개인지
