### K-3. 가이드 강조 단절 (확정, 실측 + 스크린샷)
가이드 강조가 화면 입구에서 끊긴다. 다음 다섯 곳을 고친다.
1. **영웅 목록:** 대상 영웅 카드와 '레벨업' 버튼에 펄스 강조를 둔다. 목표를 달성하면 "전투로 돌아가기" 강조로 바꾼다. 하단 내비 활성 표시가 '전투'에 남는 문제도 수정한다.
2. **편성 화면:** 신규 합류 영웅 카드에 강조와 이름표를 붙인다. 가이드 단계에서는 저장하지 않고 나갈 때 뜨는 3지선다 확인창 대신 자동 저장한다.
3. **보스 자동 소환:**
