## 1순위 — 반드시 한 번에 적용 (하나만 고치면 바로 사고)

### 1-1. 방치 보상을 실제로 받을 수 있게 [확인]
**현재**
- 필드가 5초마다, 그리고 처치할 때마다 `saveNow()`를 부릅니다(`gameState.ts:1851, 1854`).
- `saveNow()`는 매번 `lastOnlineAt`을 현재 시각으로 덮어씁니다(`gameState.ts:2517`). 그래서 앱에 돌아오고 몇 초 지나면 방치 시간이 0이 됩니다.
- 복귀할 때 보상 팝업을 띄우는 코드는 폐기된 `ui/dom/battle.ts:3433`에만 있습니다.

**수정**
- 앱을 시작할 때와 `visibilitychange`로 화면이 다시 보일 때, 첫 저장보다 먼저 아래를 실행합니다.
  - `computeOffline()`을 계산합니다.
  - 1분 이상이면 `beginOfflineClaim()`으로 보상을 고정합니다.
- 필드 화면 위에 방치 보상 팝업을 자동으로 띄웁니다. 수령 버튼만 둡니다.
- 팝업 문구는 현재 표시를 쓰지 않고 실제 지급 재화 이름으로 바꿉니다. 아래 1-2·4-1에 따라 '룬 조각'이 '던전 증표'로 바뀝니다.

**검수**
- 다음 순서를 따라가 봅니다: 필드 → 앱 숨김 → 시계 +2시간 → 복귀.
- 팝업에 120분이 표시되고 수령 후 지급되는지 확인합니다.
- 복귀 후 10초가 지나도 보상이 사라지지 않는지 확인합니다.

### 1-2. 방치 보상의 영웅 카드에서 SSR 제외 [확인]
**현재**
- 방치 1시간마다 '현재 스테이지 지정 영웅' 카드 1장을 줍니다. 12시간이면 12장입니다(`gameState.ts:2407, 2418`).
- 지정 영웅 31명 중 18명이 SSR이고, 초선·관우·조운이 들어 있습니다(`gameState.ts:1934-1944`).
- 해금 비용은 카드 1장입니다(`gameState.ts:1185`). SSR 최대 승급에는 카드 15장이면 됩니다.
- 시뮬레이션에서 방치 보상을 받는다고 하면, 21일차에 SSR 24명을 모두 모읍니다[측정].

**수정**
- 방치 카드 대상은 **C·N·R 영웅만** 남깁니다. 지정 순서표에서 SR 이상을 뺍니다.
- 지정 영웅을 아직 보유하지 않았다면 카드 대신 사료를 줍니다(카드 1장 = 사료 20). 방치만으로 영웅을 해금하지 못하게 합니다.

### 1-3. 마일리지 무한 루프 차단 [측정]
**현재**
- 승급을 끝낸 영웅의 중복 카드는 마일리지로 바뀝니다. SSR 500, SR 100, R 20, N 5, C 1입니다(`heroGrowth.ts:12`).
- 소환 1회당 평균 32.85 마일리지가 쌓입니다. 소환권 교환은 300 마일리지에 10장, 즉 1회당 30입니다(`gameState.ts:1205`). 쓴 것보다 109.5%를 돌려받습니다.
- 방치 보상을 받는 경우를 시뮬레이션하면 30일째 누적 소환이 20만 회가 됩니다.

**수정**
- 교환가: 300 → **500 마일리지에 소환권 10장**. 돌려받는 비율이 66%로 떨어집니다.
- 교환 한도: **주 3회(소환권 30장)**.
- 마일리지 수치(SSR 500 등)는 그대로 둡니다.

## 3순위 — 성장 재화 공급 곡선

### 3-1. 사료 인플레이션 [측정]
**현재**
- 30일 동안 8.7만이 들어오고 4,424만 씁니다(5%). 30일째 8.3만이 남습니다.
- 원인 1: 레벨 상한이 '20 + 출석 횟수'라 쓸 곳이 없습니다(`gameState.ts:983`).
- 원인 2: 성장 던전(레벨)이 하루 20×단계×2회를 줍니다(`contentRules.ts:22`).

**수정**
| 항목 | 현재 | 제안 |
|---|---|---|
| 성장 던전(레벨) 사료 | 20n | **3n + 20** (50단계 = 170/회) |
| 보스전(소환형) 최초 사료 | 15n | **5n** |
| 레벨업 비용 lv→lv+1 | 1+⌊lv/3⌋ | **⌈1.6×lv⌉** (Lv50까지 영웅당 약 2,000) |

- 목표: 사료 사용률 70~90%, 보유량은 3일 사용분 이하.
- 방치 사료(1-1을 고치면 다시 들어옴)를 포함해 시뮬레이션으로 다시 맞춥니다[추정].

### 3-2. 금화 인플레이션 [측정]
**현재**
- 30일 동안 1,088만이 들어옵니다. 그중 47%가 보물상자·도둑이고, 사냥 금화의 3.2배입니다.
- 원인: 발견 금화가 스테이지마다 3.5%씩 늘어납니다(`fieldDiscoveryReward.ts:5-14`).
- 쓸 곳은 사실상 금화→보석 교환뿐입니다.

**수정**
| 항목 | 현재 | 제안 |
|---|---|---|
| 도둑 금화 | 2,400×(1+0.035(s-1)) | **사냥 금화 10분치** |
| 보물상자 금화 | 900×(1+0.035(s-1)) | **사냥 금화 5분치** |
| 장비 강화 금화 | 100×(lv+1)×등급 | **×3** |
| 영향력 강화 (해금 단계 999999로 잠김, `referenceGuide.ts:23`) | 닫힘 | **[결정 필요]** 열어서 장기 소모처로 쓸지 |

### 3-3. 금화↔보석 교환 기준 [확인]
**현재**
- 금화→보석 교환가가 영웅 레벨에 지수로 오릅니다(`gameState.ts:1394-1398`, `panels.ts:543`).
  - Lv20: 금화 2,000에 보석 20
  - Lv50: 금화 약 24만에 보석 20 → 사실상 막힘

**수정**
- 기준을 스테이지 사냥 금화(선형)로 바꿉니다.
  - 보석 20 구매 = 사냥 15분치 금화
  - 보석 100 판매 = 사냥 30분치 금화
- 하루 3회 한도는 유지합니다.

### 3-4. 강화 재료 (초반 0 → 후반 폭증) [측정]
**현재**
- 14일차까지 보유량이 0~16이라 장비 가이드에서 막힙니다.
- 50스테이지 보스전이 열리면 최초 클리어 보상으로 4.6만이 들어옵니다(`contentRules.ts:23`).

**수정**
| 항목 | 현재 | 제안 |
|---|---|---|
| 보스전 최초 재료 | 15n | **3n + 10** |
| 장비 던전 | 10n | **15n + 20** |
| 장비 기능 해금 (31스테이지) | 없음 | **재료 100 지급** |
