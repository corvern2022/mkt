
## 7. 성장 곡선
| 요소 | 최대 배율 | 비용/조건 | 비고 |
|---|---|---|---|
| 레벨 | Lv30 ×7.6, Lv50 ×30.7, Lv100 **×1012** (ATK·HP·전투력) | 사료 1+⌊L/3⌋/레벨, 캡 20+출석일 | 압도적 지배 요소 |
| 승급(★) | 스탯 ×1.35, 스킬 계수 ×1.5, 지원 ×1.3, 패시브(★3)/★5 효과 | 누적 카드 SSR·SR 15, R 50, N 80, **C 120**장 | 스탯만 보면 ★5 전체 ≈ 레벨 4~5 |
| 장비(현행) | ATK +48%(무기·장갑 SSR+10 각 24%), HP +48%, 옵션(치명/스킬위력 ≤9%) | 31스테이지 해금, SSR 드랍 0.5~4% | equipmentSystem.ts:23-24 |
| 룬(레거시 모드) | 슬롯=저장★(1~6)×SSR 공격룬 +30% = **ATK +180%** | 룬 보유 계정만 전환 가능 | gameState.ts:861, 871-874. 현행 장비의 3.75배 |
| 도감 | ATK +4.92%(82명×6단계×1bp) | 획득·승급 | heroCollection.ts:8 |
| 보유 효과(5성 C/N) | 생활 +3~15% (전투 무관) | C 120장·N 80장 | 사실상 도달 불가(아래) |
| 각성 | 코드상 ×1.12/단계 | **UI 없음** | 죽은 시스템 |

Lv50 SSR ★3 기준 성장 분해(추정): 레벨 ×30.7 ≫ 장비 ×1.48 > ★ ×1.21(스킬 ×1.25) > 도감 ×1.05. 즉 중복 카드의 전투 가치는 "레벨 3~5 분량+패시브 해금"이다.
- 중복 가치: ★3 패시브(전원), ★5(SSR 고유 효과, 진영 리더 보너스)가 실질 가치. 수치 성장(+7%/단계)은 거의 체감되지 않음. 픽업 180회=카드 1장이라 관우 ★5에는 15회 천장(2,700회)이 필요하지만 방치 드랍으로 우회됨.
- C 보유효과: C 개별 확률 35%/12=2.9% → ★5(120장)까지 약 4,100회 소환. N은 30%/12=2.5%, 80장 → 약 3,200회. 효과는 +3~15%(생활)라 **목표로서 기능하지 않음**.
- SR과 SSR의 카드 비용이 같음(15장). SR 개별 확률은 0.6%, SSR은 0.125%라 SR ★5가 약 5배 쉬움(정상 범위).
