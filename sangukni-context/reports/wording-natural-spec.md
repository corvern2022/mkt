# 삼국냥전 대사·문구 자연스러움 명세 (기준 cc29b76b · 진입 `src/fieldRenewal.ts`)

- 경로는 `ait-app/src/` 기준입니다. `client/`는 보지 않았습니다.
- 이 문서는 사용자 새 지시("가이드 대사는 화면에서 방금 일어난 일에 반응하는 게임 속 대화로")를 따릅니다. 앞선 문구 문서(`codex-wording-final.md`, `codex-wording.md`, `codex-play-feedback-1007.md`, `codex-next-batch.md`)와 충돌하면 **이 문서가 우선**입니다.
  - 특히 옛 규칙 "대사는 이야기만 담고 조작은 말하지 않는다"(wording-final 1부 1장 4번)는 이렇게 바꿉니다: **대사는 지금 할 일을 '게임 속 말'로 가리킨다.** 예: "도감에 다 적혀 있어요. 같이 살펴봐요." (O) / "도감 버튼을 누르세요." (X)
- 근거 덤프: `scratchpad/r1008/wn/guide.tsv` (`fieldGuideAt(i,6,true)` 실제 해석값 1~1000단계 + 하단 캡션 + 그 단계에서 나오는 대사).
- 표기: **[확정]**은 코드 실행이나 코드 경로로 확인한 것, **[추정]**은 코드를 읽고 판단한 것입니다.
- 화면 숫자는 바꾸지 않았습니다. 대사에 숫자를 넣지 않았고, 시스템 문구의 숫자는 코드 값을 그대로 두었습니다.

## 대사가 뜨는 시점 (중요, [확정])
- 가이드 대사는 그 단계가 **"현재 단계가 되는 순간"** 뜹니다. 목표를 끝냈을 때가 아닙니다(`ui/dom/fieldLobby.ts:325-385` `storyForCurrent`, `data/guideStory.ts:109` `guideStoryLines`).
- 그래서 N단계 대사는 "(N-1)단계에서 방금 일어난 일에 반응 → N단계에서 할 일"을 말해야 맞습니다. 아래 교체안은 모두 이 기준으로 썼습니다.
- 대사창은 전투를 멈추지 않습니다. 버튼은 항상 "다음"입니다(`ui/dom/guideStory.ts:9`).

## 0. 원칙

1. **상황 → 반응 → 행동.** 한 장면은 2~3줄입니다.
   - 첫 줄: 방금 화면에서 일어난 일에 대한 반응 ("대장이 금화 상자를 두고 달아났어!")
   - 둘째 줄: 다음에 할 일을 게임 속 말로 ("짤랑거려요. 지금 열어 봐요.")
   - 버튼 이름·화면 이름·"~하세요"·"터치"·"가이드"·"목표"는 대사에 넣지 않습니다. 이런 말은 하단 가이드 캡션과 포인터 말풍선의 몫입니다.
2. **'냥' 어미 금지 (사용자 지시, 최우선).**
   - 대사를 '냥'·'냥냥'으로 끝내지 않습니다. "열어보자냥!", "잡아라냥!", "~다냥", "~요냥" 모두 금지입니다.
   - '냥'은 이름에만 씁니다: 호야냥, 태산냥, 단아냥, 황건 궁수냥, 보물 도둑냥 등.
   - 부를 때 이름 뒤 쉼표는 괜찮습니다("호야냥, 혼자 다 먹으면 안 돼요."). 문장 끝맺음이 아니기 때문입니다.
   - 고양이 의성어("냐?!", "냐옹")도 문장 끝맺음으로 쓰지 않습니다. 놀람은 "어?!", "으앗!"으로 씁니다.
   - **현재 게임 대사 중 '냥' 어미로 끝나는 줄: 0줄 [확정].** 검사 범위는 `data/guideStory.ts` 전체, `fieldLobby.ts`의 `showGuideStory` 대사 7곳, `data/fieldOpening.ts`, `ui/dom/prologueScreen.ts` 캡션, `data/audioManifest.ts` 음성 대사입니다. 정규식 `냥[!?.~…]*['"\`]`로 찾았고, 걸린 것은 모두 이름이었습니다.
   - 경계 사례 3건은 4장 E-14에 적었습니다: 프롤로그 "호야: 냐?!", 옛 STORY 화자명 "집사냥", 사용자 예시 문장의 '냥' 어미(반영하지 않음).
3. **화자와 말투를 고정합니다.**

   | 화자 | 역할 | 말투 | 예 |
   |---|---|---|---|
   | 호야냥 (m3) | 주인공. 먼저 발견하고 먼저 놀람 | 반말·감탄. "~어!", "~자!" | "저 수풀, 뭔가 반짝였어!" |
   | 태산냥 (m1) | 방패. 전투 지시 | 짧은 평서·명령. "~다.", "~라." | "놓치기 전에 잡아라!" |
   | 단아냥 (m5) | 보급·정보. 할 일을 부드럽게 권함 | 존댓말 "~요." | "지금 열어 봐요." |
   | 황건 궁수냥 / 황건 역사냥 | 합류 동료 | 기존 대사 유지(음성 녹음 있음) | — |
   | 초선냥 (신규 대사) | 7일 성장 여정 보상 동료 | 차분한 존댓말 "~요." | "이제 저도 함께할게요." |

   - 호칭은 1장까지 "호야냥", 2장부터 "호야"로 부릅니다(`codex-next-batch.md` 확정 5). 집사는 "집사님"으로 부릅니다.
4. **길이.** 대사 1줄은 **32자 이내**로 씁니다. 대화창 2줄, 한 줄 약 20자 기준입니다. 한 장면은 최대 3줄이고, 보물 상자 같은 특수 장면만 4줄까지 씁니다.
5. **반복 목표에는 대사를 넣지 않습니다.** 대사는 다음 경우에만 넣습니다.
   - 처음 하는 행동(첫 상자, 첫 장비, 첫 던전 등)
   - 새 지역 도착, 동료 합류, 장 시작·끝, 특수 이벤트
   - 같은 종류의 2번째 이후 처치·보스·레벨업은 하단 캡션만 둡니다.
6. **대사 속 용어는 화면 용어와 같게 씁니다.** 대사에서만 허용하는 말은 아래 표의 "대사" 칸에 있는 것뿐입니다.

   | 대상 | 시스템 문구 (캡션·팝업·버튼) | 대사 |
   |---|---|---|
   | 적 | 몬스터 | 황건적, 병사, 순찰대 |
   | 보스 | 보스 | 대장 (예외: "황건 장수", "순찰대장"처럼 구체적인 이름) |
   | 레벨업 재화 | 사료 | 사료 |
   | 상자 | 사료 상자, 금화 상자, 장비 상자, **보물 상자**(띄어 씀) | 같음 |
   | 소환 재화 | 소환권, 픽업 소환권 | 소환권 ("모집권" 금지) |
   | 도망치는 적 | 보물 도둑냥 | 보물 도둑냥, 도둑 고양이, 저 녀석 |
   | 아군 | 영웅 | 동료 |
   | 편성 | 편성 | "함께 갈 동료를 정하다", "자리를 정하다" |
   | 승급 | 승급 | "별을 하나 더 달다" |
   | 도감 | 도감 | 도감 |
   | 플레이어 | 집사 | 집사님 |
7. **사실과 맞게 씁니다.** 보상 종류, 상자가 나온 곳, 화면에 보이는 지역 이름은 코드와 같아야 합니다.
   - 예 1: 1-3 보물 상자 보상은 사료 20이므로(`state/gameState.ts:1842`) 대사도 "사료"라고 씁니다.
   - 예 2: 화면에 "풀숲 갈림길"이 보이는 곳에서 "둔덕"이라고 하지 않습니다.
8. **시스템 문구는 대사로 바꾸지 않습니다.** 버튼, 캡션, 토스트, 팝업은 지금처럼 짧은 명사형이나 "~시 열림" 형식을 씁니다(3장).
