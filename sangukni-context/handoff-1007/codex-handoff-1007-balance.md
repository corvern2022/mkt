## 2. 작업 순서 (제안)
1. **공통 기반**
   - 스킬 정의 테이블(`data/heroSkills.ts`)과 설명문 자동 생성
   - 밸런스 수치를 데이터 파일로 분리 (`data/balance/*.json`: 승급·레벨 상한·재화·상점 한도·평판 단계)
     - 밸런스 툴에서 바꾼 값을 그대로 반영하기 위한 작업입니다.
2. **재화 1순위 묶음** (한 번에 적용, 재화 v3 1장)
   - 방치 보상 수령 버그
   - 방치 카드 제거
   - 마일리지 루프 차단
3. **강제 튜토리얼 + 소환 재화 감축** (next-batch 1장, 재화 v3 2장)
4. **캐릭터 85종 스킬 v9**
   - 순서: SSR → SR → R → N·C
   - 함께: 진영 보너스 규칙, 스킬 치명타
5. **승급·조각·상점** (growth 1장): 레벨 상한, 배율, 조각, 마일리지·보스·평판 상점, 지역 의뢰
6. **장비 개편** (growth 2장)
7. **레벨 곡선 압축 + 스테이지 난이도 재조정** (growth 1-2)
   - 밸런스 툴에서 곡선을 확정한 뒤 별도로 전달합니다. **그 전에는 손대지 않습니다.**
8. 업적(단계형), 화면 정리·문구, iOS 성능 항목
