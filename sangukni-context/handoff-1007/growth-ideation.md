## 2. 승급(★)을 가장 강하게 — 다른 게임 참고

### 2-1. 참고 사례 (일반적으로 알려진 구조, 세부 수치는 게임마다 다름)
| 게임 | 성급(중복) 구조 | 가져올 점 |
|---|---|---|
| 서머너즈 워 | 성급(진화)이 **최대 레벨을 정함**. 6성이 되어야 만렙 40 | 승급이 레벨 상한을 열어 줌 |
| AFK 아레나 | 등급 승격 때 **레벨 상한 + 능력치 대폭 + 스킬 강화**가 한꺼번에 옴 | 승급 1회의 체감이 큼 |
| 승리의 여신: 니케 | 한계 돌파(중복) = 레벨 상한 + 능력치 % | 중복이 곧 성장 상한 |
| 블루 아카이브 | 성급 = 능력치 + 고유 스킬 강화. **전용 조각 상점**으로 중복 불운을 보완 | 확정 경로 |
| 에픽세븐 | 중복 각인 = 고유 능력치 + 팀 오라 | 중복이 팀에도 기여 |
| 세븐나이츠 키우기류 | 초월(중복) = 능력치 대폭 + 스킬 수치 강화 | 단계마다 체감 |
| 쿠키런: 킹덤 | 승급 = 레벨 상한 + 스킬 레벨 상한 | 상한 개방형 |

### 2-2. 삼국냥전 적용안 (추천 조합: A + B + D + E, C는 함께 필요)
| 안 | 내용 | 효과 |
|---|---|---|
| **A. 승급이 레벨 상한을 정함** | ★0 Lv30 → ★1 Lv40 → ★2 Lv55 → ★3 Lv70 → ★4 Lv85 → ★5 Lv100. 출석 기반 상한(20+출석)은 없앰 | 레벨을 올리려면 승급이 필요 → 승급 = 성장의 문 |
| **B. 승급 능력치 배율 확대** | 단계당 +7% → ★1 ×1.25, ★2 ×1.55, ★3 ×1.9, ★4 ×2.35, **★5 ×3.0** | 승급 1회가 레벨 여러 번보다 크게 느껴짐 |
| C. 레벨 곡선 압축 | Lv100 배율 ×1,012 → **×60 수준**으로 낮추고, 적 난이도 곡선도 같은 비율로 다시 맞춤 | 이걸 해야 B의 ×3이 의미 있음. **작업량이 가장 큼** (캠페인 난이도 전부 재조정) |
| **D. ★1·2·4에도 스킬 강화** | 0·3·5성의 효과 추가와 별도로, ★1·2·4마다 기본 스킬 계수 +10% | 매 승급마다 바뀌는 게 보임 |
| **E. 중복 불운 보완** | 영웅별 '전용 조각' (픽업 확정, 마일리지 교환, 이벤트 상점) + 등급별 '범용 승급석' (C·N·R만) | SSR ★5가 운에만 달리지 않음 |

- **비용 연동:** 승급 비용(모든 등급 2/3/5/8/12장, 확정)과 A안을 합치면 SSR이 Lv55를 넘기려면 카드 5장(★2)이 필요합니다. 첫 30일 SSR 소환 기대치와 맞는지 툴에서 시뮬레이션합니다.
- **사료와 연동:** 재화 v3의 '사료 = 레벨 상한까지 비용 × 1.1' 원칙은 A안에서도 그대로 성립합니다. 상한 기준만 출석에서 승급으로 바뀝니다.

### 2-3. 결정 필요
1. A안(승급이 레벨 상한)으로 갈지, 출석 기반 상한을 유지하면서 B안만 할지
2. C안(레벨·난이도 곡선 재조정)을 이번에 할지, 1차는 B·D만 하고 측정할지
3. E안 전용 조각의 획득처 (픽업 확정 / 마일리지 / 이벤트 상점)

## 4. 장비 — 기획 방향 (처음부터)

### 4-1. 현재 장비 [확인]
- 부위 4개: 무기, 갑옷, 장갑, 장신구
- 등급 4개: N, R, SR, SSR
- 강화: +0 ~ +10, 실패 없음
- 옵션: 1개, 리롤 가능
- 기본치: 무기·장갑은 공격, 갑옷·장신구는 체력
- 해금: 31스테이지
- 분해 환급 80%

### 4-2. 참고 방향 (방치형 RPG에서 흔한 구조)
| 요소 | 흔한 방식 | 삼국냥전 제안 |
|---|---|---|
| 부위 | 4~6부위 | **4부위 유지** (무기·갑옷·투구·장신구). 장갑 → 투구로 바꿔 직관성 높임 |
| 등급 | 5~6등급 | **5등급**: 일반 · 고급 · 희귀 · 영웅 · 전설 (색: 흰·초·파·보라·주황) |
| 주 능력치 | 부위별 고정 | 무기 공격력, 갑옷 체력, 투구 방어(받는 피해 감소), 장신구 치명/스킬 |
| 부 옵션 | 등급별 개수 | 희귀 1개, 영웅 2개, 전설 3개. 리롤 가능 |
| 강화 | 단계 + 돌파 | +0~+15, **실패 없음**. +5·+10에서 '돌파' (같은 부위 장비 1개 소모 → 남는 장비 소모처) |
| 세트 | 2·4세트 효과 | **콘텐츠 세트** — 철갑 세트(보호막 피해 +), 화염 세트(화상 저항), 성문 세트(감속 강화) 등. 8장 '던전별 상위 캐릭터'와 연결 |
| 귀속 | 영웅 귀속 또는 자유 | **자유 교체** + 자동 장착 + 일괄 강화 (방치형에 맞게 편하게) |
| 획득 | 던전 중심 | 장비 던전(주) · 보스전 · 필드 드롭. 분해 → 강화 재료 |
| 전용 장비 | SSR 전용 | 업데이트 스펙으로 보류 (말·펫과 같은 시기) |

### 4-3. 장비 비중 목표
- 30일차 전투력의 약 25%, 장기 25~30%입니다. 1장의 목표표와 같습니다.
- 강화 비용은 재화 원칙('편하게 성장, 재화는 남지 않게')에 맞춥니다. 장비 던전 하루 보상 ≈ 하루 강화 수요 × 1.1입니다.

### 4-4. 결정 필요
1. 부위 4개 유지 (장갑 → 투구) / 6부위로 확장
2. 등급 5등급 / 현재 4등급 유지
3. 세트 효과를 넣을지 (콘텐츠 세트 추천)
4. 강화 실패 없음 (추천) / 확률 강화
5. 돌파에 같은 장비 소모 (남는 장비 처리) 여부

## 5. 밸런스 툴에 들어갈 화면 (Codex 푸시 후 제작)
1. **전투력 구성:** 레벨·승급·장비·진영·도감 비중을 시점별(1/7/30/90일)로, 현재 안과 제안 안을 나란히 보여줌
2. **성장곡선:** 영웅별 레벨 × 승급 곡선, 등급·클래스 비교, 같은 투자 대비 성장
3. **포텐셜 100점:** 단일·광역·생존·지원·콘텐츠 특화 레이더 차트, 서열표와 어긋나면 표시
4. **평타 표:** 85종 평타 형태(단일·반원·관통·연쇄·소범위)
5. **장비 시뮬레이터:** 등급·강화·옵션 조합별 수치, 재화 공급 대비 도달 일수

- 수치를 바꾸면 그래프가 바로 다시 계산됩니다.
- 확정한 값은 데이터 파일(JSON)로 내보내 Codex가 반영합니다.
